# Why Codex Native

Codex skills are the appropriate unit for reusable workflows because they provide explicit and implicit invocation, progressive disclosure, optional references and scripts, and plugin packaging. Keeping the source as Claude slash commands would preserve text but not create an installable Praxis Skills package.

The port preserves the original artifact chain and role nuance while replacing Claude-only runtime assumptions with Codex-native skills, references, optional subagents, MCP dependency declarations, and repeatable audits.
